\subsection{System model}

\method{} targets multi-agent coding prefill in which:

\begin{itemize}[leftmargin=1.2em,itemsep=0.2em]
    \item Each \textbf{task} is a repository-level issue: a natural-language
          specification, a codebase snapshot, and hidden tests that never
          enter the prompt.
    \item Each \textbf{turn} is one role request under a rolling-6 history
          (the last six complete role groups, compacted).
    \item A \textbf{file module} is a contiguous \texttt{repository\_code}
          span for one path at one content version.
    \item The serving engine hosts Dense prefill and optional island copy
          on shared GPU memory.
\end{itemize}

A source request encodes a file at start index $s$. A later target request
needs the same token IDs at start index $t$. Write
$\Delta = t - s$. Ordinary prefix reuse applies only if $\Delta = 0$ and
the bytes to the left also match. We study the complementary case
$\Delta \neq 0$.

\subsection{Design goals}

\begin{enumerate}[leftmargin=1.2em,itemsep=0.25em]
    \item \textbf{True lossy, not prefix in disguise.} Copied token IDs
          must match the target, and the logical shift is
          nonzero. Zero-shift islands are dropped so the method cannot
          degenerate to a prefix cache.
    \item \textbf{Fail closed.} When $\Delta$ is known, the eval path
          pre-rotates source $K$ so residual $\Delta=0$ at copy; the
          served path rotates after unique-span bind. A mechanically
          invalid island is discarded and Dense-recomputed. Never serve
          a partial island.
    \item \textbf{Cache-ready TTFT.} Target TTFT is reported after source
          KV already exists, against the same engine's Dense, matching
          CacheBlend and KVCOMM. Prefetch stays off in the headline 7B
          campaign. One-token agreement is not official resolved.
\end{enumerate}

\subsection{What would invalidate a claim}

Mixing a 7B official-Accuracy table with the 7B or 30B TTFT numbers as
if they were one method. Calling cache-ready $1.492\times$ a one-use
wall-clock serving win. Calling $93.6\%$ one-token agreement
Accuracy. Enabling prefetch or radix prefix reuse and attributing
the gain to coding-aware copy. Editing the residual-$\Delta$
gate after seeing outcomes. Mixing the appendix 30B campaign's
$1.375\times$ into Table~\ref{tab:eval-summary}.
